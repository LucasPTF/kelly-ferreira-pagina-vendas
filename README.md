# Workshop Mapa do Automático

Página de vendas desenvolvida exclusivamente para Kelly Ferreira, especialista em Engenharia do Comportamento Feminino.

## Tecnologias

* Next.js 16
* React 19
* TypeScript
* CSS responsivo
* Next Image

## Rotas

* `/a1`
* `/a2`
* `/a3`
* `/obrigado`

As três páginas de vendas compartilham componentes, conteúdo, oferta e identidade visual. Apenas a comunicação da abertura muda entre as rotas.

## Execução local

```bash
pnpm install
pnpm dev
```

Abra `http://localhost:3000/a1` no navegador.

## Build de produção

```bash
pnpm build
pnpm start
```
